## Теоретическая справка

**Тестирование информационной системы (ИС)** — это проверка того, что система работает правильно: сервисы отвечают, файлы на месте, процессы запущены, данные не повреждены.

**Принцип любого теста в bash:**
- Тест — это команда, которая возвращает **код 0** (успех) или **не 0** (провал).
- `echo $?` показывает код возврата последней команды.
- Скрипт-тест можно запустить вручную или по расписанию.

**Простейшие инструменты:**
| Инструмент | Для чего |
|---|---|
| `test` / `[ ]` | Проверить файл, каталог, права |
| `curl` | Проверить HTTP-сервис |
| `pgrep` | Проверить, запущен ли процесс |
| `grep` | Найти текст в файле или выводе |
| `ping` | Проверить доступность узла |

## Часть 2. Базовые принципы теста

### Как работает проверка в bash

Любая команда возвращает **код возврата**:
- `0` — успех;
- `1` (или другое число) — ошибка.

```bash
# Проверяем код возврата
ls /etc/passwd
echo $?          # 0 — файл есть

ls /nonexistent
echo $?          # 2 — файла нет
```

### Функция проверки

Все тесты в работе используют **одну функцию** `check`. Она:
1. Принимает название теста и команду.
2. Выполняет команду.
3. Печатает `PASS` или `FAIL` в зависимости от кода возврата.

Создайте файл `check.sh`:

```bash
nano check.sh
```

Введите код (комментарии подробные):

```bash
#!/bin/bash
# Функция проверки. $1 — имя теста, дальше — команда для выполнения.

PASS=0   # счётчик пройденных
FAIL=0   # счётчик проваленных

check() {
    local name="$1"           # сохраняем название теста
    shift                     # убираем название, остаётся команда
    if "$@" >/dev/null 2>&1; then   # выполняем команду молча
        echo "PASS: $name"    # код 0 — тест пройден
        PASS=$((PASS + 1))
    else
        echo "FAIL: $name"    # код не 0 — тест провален
        FAIL=$((FAIL + 1))
    fi
}
```

**Как это работает:**
- `local name="$1"` — берём первый аргумент (имя теста).
- `shift` — сдвигаем аргументы: теперь `$@` — это команда.
- `"$@" >/dev/null 2>&1` — выполняем команду, глушим весь вывод.
- `if ...; then` — проверяем **код возврата** команды.
- `PASS=$((PASS + 1))` — увеличиваем счётчик.

> **Подключение:** чтобы использовать `check` в других скриптах, добавьте в начало файла строку:
> ```bash
> source ~/qa/check.sh
> ```

## Часть 3. Набор простейших тестов

Все скрипты ниже. Каждый можно запускать отдельно.

### Тест 1. Проверка файла данных

Создайте `test_file.sh`:

```bash
#!/bin/bash
source ~/qa/check.sh

# -s — файл существует И не пустой
check "Файл users.csv существует и не пуст" \
    test -s ~/qa/data/users.csv

echo "Пройдено: $PASS, Провалено: $FAIL"
```

**Запуск:**
```bash
chmod +x test_file.sh
./test_file.sh
```

**Ожидаемый вывод:**
```
PASS: Файл users.csv существует и не пуст
Пройдено: 1, Провалено: 0
```

**Что проверяет:** `test -s FILE` возвращает 0, если файл существует и его размер больше нуля.

---

### Тест 2. Проверка количества строк

Создайте `test_lines.sh`:

```bash
#!/bin/bash
source ~/qa/check.sh

# wc -l считает строки; сравнение через -eq 3
check "Файл users.csv содержит 3 строки" \
    bash -c "[ \"\$(wc -l < ~/qa/data/users.csv)\" -eq 3 ]"

echo "Пройдено: $PASS, Провалено: $FAIL"
```

**Запуск:**
```bash
chmod +x test_lines.sh
./test_lines.sh
```

**Что проверяет:** `wc -l < FILE` читает файл через перенаправление (без имени файла в выводе) и сравнивает с числом.

> **Важно:** `\$(...)` внутри двойных кавычек экранировано, чтобы подстановка произошла **внутри** `bash -c`, а не раньше.

## Часть 4. Запуск всех тестов одной командой (10 минут)

Создайте `run_all.sh`:

```bash
#!/bin/bash
# Запускает все тесты по очереди

for test in ~/qa/test_*.sh; do
    echo "--- $(basename $test) ---"
    bash "$test"                 # выполняем очередной тест
done
```

**Запуск:**

```bash
chmod +x run_all.sh
./run_all.sh
```

**Ожидаемый вывод:**

```
--- test_content.sh ---
PASS: В файле есть заголовок 'id,name,status'
Пройдено: 1, Провалено: 0
--- test_file.sh ---
PASS: Файл users.csv существует и не пуст
Пройдено: 1, Провалено: 0
...
```

**Разбор кода:**
- `for test in ~/qa/test_*.sh` — перебираем все файлы, начинающиеся с `test_`.
- `$(basename $test)` — печатаем только имя файла без пути.
- `bash "$test"` — запускаем очередной тест.
