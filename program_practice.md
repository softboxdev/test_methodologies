## Тема 3.7.1. Автоматизация: Selenium (НОВЫЙ БЛОК)

| № занятия | Практическое занятие | Содержание |
|-----------|---------------------|------------|
| 17.1 | Введение в Selenium. Установка и настройка | WebDriver, Selenium IDE, Selenium WebDriver. Установка Python/Java + Selenium. Драйверы браузеров (ChromeDriver, GeckoDriver) |
| 17.2 | Поиск элементов и локаторы в Selenium | By.id, By.name, By.className, By.tagName, By.linkText, By.partialLinkText, By.cssSelector, By.xpath. Приоритет локаторов |
| 17.3 | Взаимодействие с элементами | Клик, ввод текста, очистка поля, отправка формы, работа с выпадающими списками (Select), чекбоксами, радиокнопками |
| 17.4 | Ожидания в Selenium | Implicit Wait, Explicit Wait, Fluent Wait. WebDriverWait, ExpectedConditions. Обработка динамических элементов |
| 17.5 | Написание первого автотеста на Selenium | Открытие страницы, поиск элемента, действие, проверка результата (assert). Запуск в разных браузерах |
| 17.6 | Selenium + unittest/pytest | Структура тестов, фикстуры, параметризация, отчёты о запуске |
| 17.7 | Page Object Model (POM) | Проектирование структуры автотестов, вынос локаторов и действий в отдельные классы |
| 17.8 | Работа с окнами, фреймами, алертами | Переключение между окнами и вкладками, работа с iframe, обработка JavaScript-алертов |
| 17.9 | Скриншоты и логирование в Selenium | Снятие скриншотов при падении теста, ведение логов, интеграция с Allure |
| 17.10 | Selenium Grid. Параллельный запуск | Запуск тестов на разных браузерах и ОС одновременно |

**Задание:** Написать автотест на Selenium для проверки формы авторизации. Использовать явные ожидания, Page Object Model, сделать скриншот при падении теста.
